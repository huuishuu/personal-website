Hexis

Hexis was a free-to-play rhythm game made by Dienay Games released some time in 2012 as an Alpha and in 2014 moved to Beta.
It featured a single game mode, very reminiscent that of Elite Beat Agents, Osu! Tatakae! Ouendan and osu! with plans for more in the future that never came through.

The game features an in-game editor for creating your own beatmaps.

The official Hexis website shut down on April 19th, 2017.
The last official update Hexis has received was on April 9th, 2015 and the latest version is v0.5.105 Beta.

Things to keep in mind

  • The game isn't very well optimized and may have trouble running on modern hardware. See the Support page for details if you're having trouble.
  • The game's development was abandoned after v0.5.105 beta, so some features have never been implemented.
  • There is no way to play this online anymore, as both the Hexis website and the online servers have been shut down.
