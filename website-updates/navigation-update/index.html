Navigation Update

5/3/2024

 
Doing a trial run of a navigation update for this website, since navigating it has been thus far the most confusing aspect about the website and the one thing that I've consistently cited as a major issue with the website. Starting now, I'm experimenting with attempting to improve the navigation of the website.

Here's what I've changed:
  • Hid the Hexis Support Page, now it's hyperlinked in the main Hexis page
  • Hid the pages for my deleted maps, unfinished maps, etc. and replaced everything with a central hub page with a directory leading to each specific page that you might need
  • Hid the pages for my osu! skins years and replaced everything with a central hub page with a directory leading to each specific page sorted by year
  • Added a short About page

Yes, I do realize that I've already mentioned a few of these changes already but, as you can tell, that was leading up to this update to the site that I've been thinking of doing anyway, so I thought it'd make sense to just group everything together into one.

I have also massively overhauled the Safari Biathlon Racer page, as well as the Open Hexagon page. The Safari Biathlon page mainly just got cleaned up, removing a lot of unnecessary information, formatting and also adding an alternative download link for the game. Please be sure to read the disclaimer about the alternative download link though.

The Open Hexagon page mainly had something done to it that I'm surprised I have never done in the "10 years" that this website's been around - added level pack descriptions and, way more importantly, properly crediting artists for their music that's used within the level packs!

Oh, and I've also linked the archive.org download for Hexis as well. Even if that upload is literally just a reupload of my own archive of Hexis, it's still helpful to have alternative sources.

Let me know if navigation of the website is better with this update, or if I should revert to how it was before.

Next up on the to-do list to fix on the site is probably cleaning up & fixing the MEGA links, as I just tested them and they're either broken or just link to the general MEGA folder where everything's kinda just there. I'll sort it out probably tomorrow or during the weekend, we'll see how things go.

Thanks, and have fun.

- huu
