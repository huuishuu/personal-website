Domain Name Change & Future Plans

4/30/2024

 
Starting today, this website's domain is being changed from shfoh.weebly.com to huuishuu.weebly.com

All of this is part of the process to rebrand this website from being about Open Hexagon to be my own personal space to post & do personal things.

After 10 years, it is finally time to ditch the old name. In case you're wondering what's happening with the old domain, I'm turning it into a hacky redirect to this site now. Weebly's tools are very poor to allow you to add your own redirect, I couldn't figure it out, so visiting the old site will just give you a big "MOVED" text thingy, since that's the best I could do.

Another huge change I've made is that I've restructured the website's navigation a little bit. The Hexis and Safari Biathlon Racer pages have been moved into their own category that I've made, called "Abandonware", since these games are effectively that.

I'm also in the process of adding in my own personal unfinished osu! map stuff to the website. Hovering over the "osu!" category, you will see a new addition specifically relating to my own mapping stuff. Currently, the following pages are accessible / finished:
- Deleted Maps - a page dedicated to hosting my own deleted sets from osu!
- Unfinished Maps - a page dedicated to hosting maps that I've started but never finished. This includes collabs!
- Timed Songs - a page dedicated to maps that I've only timed but never got started on mapping.

The 4th page, Old Versions, is currently under construction. I ran out of time today to work on it, so I'll add it at a later point.

Later on, I will also work on adding a page dedicated to housing all of my osu! skins that I've ever made. I have quite the extensive backlog going back to 2015 and could never find a consistent way of housing them, but I think I could use my own personal site for that. So that's on my to-do list for now.

One more thing - I've done some spring cleaning on the website. There were A LOT of legacy pages on this site from 2014-2017 that were only ever sparsely used. You probably didn't know about them because they've been hidden for so long! Well, starting today, most of them have finally been deleted & the contents of those pages - erased. Don't worry, nothing of value was lost! Mainly things like an old FAQ page that became redundant, an old "About" page, etc.

I've only kept a few "hidden" pages - such as the old "News" page linked on the sidebar, or the page for my old Open Hexagon packs' previous versions. Oh, and the Need for Speed World page is technically still there but I've hidden it. The download on that page also doesn't work, as it's been DMCA'd by EA back in 2016.

That's all for today. I'll be back probably later in the week with new additions.

p.s. Yes, this website is still blocked in CIS regions. I can't do anything about that, I'm sorry.

- huu
