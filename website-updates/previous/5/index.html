More submission issues fixed!

11/8/2016

 
For a good while, pretty much ever since I started the entire submission to SHfOH shmuck, I've always had an issue with submissions going to the "Spam" folder automatically by my email provider. Usually though, it was resolved by marking the emails as "important", moving them to my Inbox instead of the Spam folder and then my email provider would see that emails like that aren't exactly spam, so it'd start putting them in my inbox instead.

However, it didn't happen this time and never happened over the course of 4 months. Having missed shivaco's new submissions, I decided to take some kind of action. I've tried adding the [email protected] email as a contact, so the email provider would know that I'd like to receive emails from that account regularly. No dice, still marked as spam. In the end though, I had to disable my spam filter in general so I'd get notified about submission emails.

Once again, thanks to shivaco for kickstarting me into doing something about this, and I'm sorry for an inconvenience anyone suffered thanks to this.
-Site Owner

Regarding new beatmaps & beatmap updates

10/26/2016

 
Hey all. It's huu. Since osu! support has been ignoring me for the last 3 weeks regarding my ban appeal, I've pretty much given up on trying to get unbanned on official osu!, so I'm here to make an announcement regarding any new beatmaps I make and when I decide to update an existing map.
