Safari Biathlon Racer

Safari Biathlon Racer is a sci-fi racing game developed in the early 2000s by the Russian developer Nikita Interactive (nowadays known as Nikita Online).

The game features 3 planets with 3 tracks each, power-ups & pickups to aid you during a race and about 15 different vehicles with varying top speeds, acceleration & mass.

Each car also comes equipped with a gun to shoot your opponents out of the way. Strategic use of the weapon on your vehicle is the key to success within this game, though aside from having different particles & sounds, all guns on every car are equally effective as each other.

System requirements

Operating System: Windows ® 95/98/ME (DirectX 8.x or higher)
Processor: Intel Pentium® II 266 MHz (Intel Pentium® III 500 MHz or AMD Athlon recommended)
RAM: 64 MB RAM (or higher)
Graphics: MS Direct3D compatible 3D-accelerator
Sound: MS Windows compatible Sound system
Control: Keyboard

Other relevant information

  • This game does not have native controller support, so using a controller is not recommended.
  • Using a computer with Windows 98 preferably is recommended.
  • The game does not work with virtual machines.
  • Anything above Windows 7 and x64 operating systems may have trouble running this game.

If you wish to change the resolution - go to the game's directory and edit display.cfg. You can also change graphical settings here!
This might cause unintended side effects though, so be careful with modifying that file.
