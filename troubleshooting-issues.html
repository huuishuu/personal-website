Having issues running Hexis?

As mentioned in my Should You Play? video on Hexis, this game is not very well optimized and tends to run very poorly, especially on modern operating systems and hardware.

I've made this page to essentially help you troubleshoot issues with Hexis, should you want to try the game for yourself.

I'm getting an error regarding "msvcr120.dll" being missing.

This means you are missing dependencies for the game to start. Most Google searches will tell you to "reinstall the program", when in reality - you're just missing the Visual C++ 2013 Redistributable package.

You can download the redistributable from the Microsoft website linked below.
Visual C++ 2013 and Visual C++ Redistributable Package
Install both the x86 and x64 versions in accordance to your operating system's language settings, and you should be good to go! Try running Hexis after you've installed this.

Text is cut off or off-screen in menus & gameplay.

This is a common issue for anyone running the game on an operating system newer than Windows 7. There is no easy fix for this, other than attempting to set compatibility settings for Hexis to Windows 7.

Game won't start on Linux.

Unfortunately, I was not able to find a fix for this myself. Tested on my Linux Mint machine running version 21.3 "Virginia", using both Wine & Proton, the game would refuse to boot.

If anyone finds a way to make the game work under Linux, please let me know!
